# 四領の書 — 兼務役職のためのタスク管理ボード

芳川恒徳が兼務する役職ごとに、タスクの進捗を一画面で管理するための盤。
三国志風の意匠で、Claude Artifact として公開して動かしている。

## 何を管理するか

| 領地 | 実体 | 性質 |
|---|---|---|
| HAL | 行政書士法人HAL 役員 | 統治（執行） |
| GEMA | 外国人材雇用マネジメント協会 代表理事 | 統治（執行） |
| Awillize | 個人名義の発信・教材 | 統治（執行） |
| 海羽会 | 医療法人社団海羽会 監事 | 監察 |
| APSIP | 国際人材普及振興協会 監事 | 監察 |
| 工房 | AI基盤・実験 | 別枠（装備） |

## 画面

- **本営** — 戦勝・制圧・金、注進（期限切れと直近の期日）、領地一覧
- **領地** — 任務の一覧（主命／策／日課／戦果）、巡察、軍師に相談する
- **モジュール管理** — 収益導線。共通の集客 → 複数の入口 → 合流 → 一本の本線
- **武将一覧** — 任務を委ねる相手。得手と命の受け方を持つ

## 仕組み

- 単一のHTMLファイル。Claude Artifact の `db` と `sample` を使う
- `db` に任務・巡察・モジュール・軍師・武将・報告・書庫を保存
- `sample` で軍師（諸葛亮）への相談と、武将への下命を行う
- 書庫は PDF・.docx・.pptx・テキストから本文を取り出して保持する

## 構成

```
shiryou-no-sho.html   盤の本体（これ一つで動く）
docs/design.md        設計書。決定と理由の記録
```
